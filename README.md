# Invitation settings

Edit `config.json` to change the default venue, time or map link on every invitation. No Netlify deploy is needed.

- `map`: Google Maps link for the View Location button
- `time_en` / `time_ne`: time shown on the English / Nepali cards (leave "" for none)
- `venue_en` / `venue_ne`: venue name shown on the English / Nepali cards (leave "" for none)

Changes reach guests within about 5 minutes.
